# مِران

تمارين ذهنية يومية بالعربي — صفحة واحدة تشتغل بدون إنترنت بعد أول فتحة.

مستقلة تمامًا عن دعوة التخرج في جذر المستودع؛ هي هنا فقط لأن GitHub Pages
مفعّلة على هذا المستودع.

## التشغيل

**Settings ← Pages ← Branch: `main` / `(root)` ← Save**

بعدها الرابط: `https://<username>.github.io/Rawan-grad/miran/`

## على الآيفون

افتحي الرابط من سفاري ← مشاركة ← **إضافة إلى الشاشة الرئيسية**.
تفتح بملء الشاشة بأيقونتها، وتشتغل بدون إنترنت.

## أين تُحفظ البيانات

المستويات والدرجات والسلسلة والملاحظات كلها في **متصفحك على جهازك**
(`localStorage`). لا تُرسل لأي خادم، ولا يوجد حساب ولا تسجيل دخول.
مسح بيانات الموقع من إعدادات المتصفح يمسحها.

## الملفات

| | |
|---|---|
| `index.html` | الصفحة كاملة — التمارين والتقرير والأنماط والسكربت |
| `sw.js` | عامل الخدمة، يخزّن الصفحة للعمل بدون إنترنت |
| `manifest.webmanifest` | اسم التطبيق وأيقونته وألوانه ووضع ملء الشاشة |

## تحديث الصفحة

ارفعي `index.html` الجديد وخلاص. عامل الخدمة يجيب الصفحة من الشبكة أولًا،
فالتحديث يظهر عند أول فتحة بعد انتهاء بناء Pages (دقيقة تقريبًا) — بلا أي
خطوة يدوية. الأصول الثابتة (الأيقونات) تُقدَّم من المخزون وتُحدَّث في الخلفية.

وبدون إنترنت: كل شيء يُقدَّم من المخزون كما هو.
