# دعوة حفل تخرج — روان الخراز

صفحة دعوة عربية (RTL) بستايل كوكيت، ملف واحد يفتح على أي جهاز بدون إنترنت بعد أول تحميل.

| الملف | وش فيه |
|---|---|
| `index.html` | النسخة الفاتحة — وردي فاتح وكريمي |
| `original-burgundy.html` | النسخة الأصلية العنّابية، محفوظة للرجوع |

## وش فيها

- غلاف ظرف يتفتح لما تضغطين على الختم
- عدّاد تنازلي لموعد الحفل
- برنامج الحفل بالتفصيل
- أزرار: أضف للتقويم · مشاركة · افتح الموقع على الخرائط
- الخطوط مدمجة داخل الملف: Aref Ruqaa و Amiri و Almarai و Cinzel

## تعديل التفاصيل

كل النصوص مكتوبة مباشرة داخل `index.html` — افتحيه بأي محرر ودوّري على الاسم أو التاريخ وغيّريه.

المواعيد والعدّاد مضبوطة من متغيّر التاريخ في السكربت أسفل الملف.

## الألوان

الألوان معرّفة كمتغيّرات CSS في أول `<style>`:

```css
--paper   /* خلفية الكرت */
--ivory   /* كريمي ثانوي */
--wine    /* النص الأساسي */
--wine-tx /* النص الثانوي */
--wine-dp /* خلفية الصفحة */
--gold    /* اللون المميّز */
```

تغيير هذي الست يغيّر شكل الدعوة كامل.

## النشر

الملف مستقل تمامًا — ارفعيه على أي استضافة (Netlify أو GitHub Pages) أو افتحيه من الجهاز مباشرة.

> ⚠️ الصفحة فيها أسماء وعنوان سكن حقيقي. لا ترفعينها على استضافة عامة إلا وأنتِ موافقة إنها تنفتح لأي أحد يعرف الرابط.
