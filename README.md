# دعوة حفل تخرج — روان الخراز

صفحة دعوة عربية (RTL) بستايل كوكيت، ملف واحد يفتح على أي جهاز بدون إنترنت بعد أول تحميل.

| الملف | وش فيه |
|---|---|
| `index.html` | **نسخة العرض** — أسماء وعنوان وهمية، جاهزة للنشر والدعاية |
| `original-burgundy.html` | نفس الدعوة باللوحة العنّابية الأصلية — بيانات وهمية كذلك |

## وش فيها

- غلاف ظرف يتفتح لما تضغطين على الختم
- عدّاد تنازلي لموعد الحفل
- برنامج الحفل بالتفصيل
- أزرار: أضف للتقويم · مشاركة · افتح الموقع على الخرائط
- الخطوط مدمجة داخل الملف: Aref Ruqaa و Amiri و Almarai و Cinzel

## تعديل التفاصيل

كل النصوص مكتوبة مباشرة داخل `index.html` — افتحيه بأي محرر ودوّري على الاسم أو التاريخ وغيّريه.

المواعيد والعدّاد مضبوطة من متغيّر التاريخ في السكربت أسفل الملف.

## الألوان

كل ألوان النص سُلّم واحد: **درجة 340° وتشبّع 30%**، ما يتغيّر إلا السطوع. التمييز يفترق بالتشبّع (42%) لا بالدرجة، عشان يظل من نفس العائلة.

```css
--wine-dk /* #713D4E — L34% — اسم الخريجة والعناوين الكبيرة */
--wine    /* #85475C — L40% — النص الأساسي */
--wine-tx /* #955B6E — L47% — النص الثانوي */
--gold    /* #AA4667 — S42% — التمييز والخطوط الرفيعة */
--paper   /* خلفية الكرت */
--ivory   /* كريمي ثانوي */
--wine-dp /* خلفية الصفحة */
--gold-lt /* تِنت وردي للزخارف والكونفيتي */
```

لا تكتبي لون نص مباشرة في القاعدة — استعملي متغيّر من السُلّم، وإلا تتراكم درجات متقاربة تكسر التجانس. السطوع المذكور هو أفتح ما يقدر عليه اللون وهو محقّق تباين 4.5:1 على الكريمي؛ لو فتّحتيه أكثر يسقط الفحص.

## فحص الصفحة

```bash
npm i playwright
node check.js index.html
```

يطلّع تقريرًا بستة فحوص، أهمها اثنان يصعب اكتشافهما بالعين:

- **نِسب الصور** — يقارن النسبة المعلنة في CSS بأبعاد الصورة الحقيقية. الفرق هنا كان يخلي زخارف الزوايا تطفو بعيدة عن مكانها.
- **كثافة الكونفيتي** — يقرأ قناة الشفافية من الكانفس مباشرة ويضربها في شفافية الطبقة. سجّلي الرقم قبل أي تعديل على الشفافية وقارنيه بعده؛ قياس اللقطات لا ينفع لأن القطع عشوائية.

وكذلك: عناصر عالقة على شفافية صفر · تباعد حروف على نص عربي · تباين كل نص · بقايا اللوحة العنّابية.
